# Morse_Code_Trainer
This is the oficial repo for the project "Morse Code Trainer" from SFZ Ulm with Benjamin G. and Falko S. 
The mission is to bring "Old rusty morse code" back to Children in a fun and easy way. We have planned online games and daily challenges. 
All design is made by us in the "Schuelerforschungszentrum Suedwuerttemberg Standort Ulm".
