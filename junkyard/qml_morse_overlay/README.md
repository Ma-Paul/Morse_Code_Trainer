# Binäreingabe Overlay — QML Version

This folder contains a QML/Qt Quick conversion of the provided `script.py` Pygame overlay.

## Run on macOS

1. Install Qt with QML support, for example:
   - `brew install qt`, or
   - install Qt 6 from the official Qt installer.
2. Double-click `run.command`, or open Terminal in this folder and run:
   - `qml main.qml`
   - or `qmlscene main.qml`

## Controls

- `Enter`: continue
- `Escape`: back / quit from start
- Left and Right arrows: Morse input/test keys
- `Space`: finish current character in input mode
- `Backspace`: delete
- `Ctrl+Q`: quit
